The MODEST Framework

Architecting Intelligent Solutions for Clinical Mental Health Diagnostics

Framework Architecture

The MODEST framework is a generalized Multimodal Fusion Framework designed to automatically estimate mental disorder scores and enable early clinical interventions. It integrates multiple data modalities to create a robust, 360-degree representation of a user's mental state.

Multimodal Input Integration

Visual (Image/Video): Uses CNNs (e.g., ResNet, VGGFace) for face detection and expression encoding to capture non-verbal distress cues.
Audio (Speech): Analyzes prosodic features (pitch, tone, pauses) and MFCC for emotional markers, using tools like Librosa and Whisper.
Text (Transcript): Converts audio to transcripts using Speech-to-Text APIs and generates document embeddings using BERT and Paragraph Vector models.
Physiological (EEG/GSR): Processes real-time brain activity and skin conductance data from Bluetooth-enabled wearables to measure physiological stress.

Core AI Techniques

Fusion Models: Employs Early (feature-level), Late (score-level), and Hybrid (Cross-Attention) fusion techniques.
Explainable AI (XAI): Incorporates XAI-enabled frameworks to provide interpretable diagnostic insights for clinicians.
Domain Adaptation: Uses cross-attention mechanisms to understand relationships between demographic factors and mental illness.

System Deliverables

Mobile Application: A beta version is under design to record user audio/video and connect with EEG wearables.
Web-based UI: An interactive interface for real-time mental health assessments and visual analytics.
"We are building a space where the multimodal (the technical) meets the modest (the humble, human-centric approach), allowing for a radical rediscovery of the self"

Project Identity

Multimodal Analysis for Mental Disorder Recognition to Improve Mental Health and Well-being.An initiative at the BDA Lab, IIIT Allahabad, aimed at integrating AI-driven diagnostics with culturally grounded perspectives to support more accessible, equitable, and context-sensitive mental health solutions
